# Plan for convert_GOSIF_v2_tiff_monthly_to_netcdf.py

1. **Dependencies**
   - Python 3.x
   - Packages: `xarray`, `rioxarray`, `netCDF4`

2. **Script Path**
   `/home/chc-source/shrad/Scripts/Funded_projects/2026/crop_yield_forecasting/code/python/convert_GOSIF_v2_tiff_monthly_to_netcdf.py`

3. **Output Path**
   `/home/chc-shrad/DATA/SIF/GOSIF_v2/netcdf/monthly/`
   Files named `GOSIF_v2_<YEAR>.nc`.

4. **Command‑line arguments**
   - `--data-dir`: directory with monthly GeoTIFFs (default provided)
   - `--out-dir`: directory for yearly NetCDFs (default provided)
   - `--verbose`: optional flag for extra prints

5. **Processing Logic**
   - Collect all `GOSIF_*.tif` files.
   - Group by year extracted from filename.
   - For each year:
     * Load each month with `rioxarray.open_rasterio(..., masked=True)`.
     * `squeeze()` to drop band dim.
     * Create mid‑month `datetime` for time coordinate.
     * Concatenate along `time` dimension with `xr.concat`.
     * Write NetCDF with `da.to_netcdf(..., format="NETCDF4", engine="netcdf4")`.
   - Print minimal status messages. Use `print()`; no logging module.

6. **Metadata**
   - Rely on rioxarray to preserve CRS, bounds, and no‑data.

7. **Execution**
   - The script can be run directly.
